# ADR-001: Uso de PostgreSQL

**Estado:** Aceptado

## Contexto
La aplicación necesita persistir contactos, conversaciones y mensajes.
También debe mantener consistencia entre mensajes y cantidad de mensajes no leídos.

## Alternativas consideradas
- PostgreSQL
- SQL Server
- MongoDB

PostgreSQL ofrece un modelo relacional, transacciones, restricciones e integración
madura con Entity Framework Core.

MongoDB permitiría mayor flexibilidad de esquema, pero el dominio planteado es
claramente relacional y no requiere esa flexibilidad.

SQL Server también es una opción válida, pero PostgreSQL resulta más liviano y
simple de ejecutar dentro de Docker para esta prueba.

## Decisión
Se utilizará PostgreSQL con Entity Framework Core.

## Consecuencias
Se obtiene consistencia transaccional, integridad referencial y facilidad para
realizar consultas sobre conversaciones y mensajes.

Como contrapartida, el esquema requiere migraciones cuando cambia el modelo de datos.
